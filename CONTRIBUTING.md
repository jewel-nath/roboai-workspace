# Contributing

RoboAI Workspace is being redesigned; a full contributor guide comes in Phase 7 of the
[plan](docs/plan.md). Until then, contributions follow the same rules agents do, in
[AGENTS.md](AGENTS.md).

## What helps most

- A Robot Atlas profile of a robot you have built or studied closely.
- A part page with real numbers from use, not only the datasheet.
- A trap you hit with a tool, with how to tell and how to fix it.

## Before you open a pull request

- [ ] The page uses its template from [templates/](templates/) and the fields in
      [docs/frontmatter.md](docs/frontmatter.md).
- [ ] Every number has a source; `evidence` and `last_verified` are set.
- [ ] Facts are in your own words; other people's files are linked, not copied.
- [ ] Anything taken from outside has an entry in [sources/registry.yaml](sources/registry.yaml).
- [ ] No secrets, machine-specific paths, rendered media or files from `vendor/`.
- [ ] One topic per pull request.
