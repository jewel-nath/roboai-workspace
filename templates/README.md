# Templates

Copy a template, rename it to the page's slug, fill in what you know and leave the rest empty.
Fields are defined in [docs/frontmatter.md](../docs/frontmatter.md). HTML comments in a template
are guidance; delete them as you fill each section.

| Template | For | Goes to |
|---|---|---|
| [robot.md](robot.md) | A Robot Atlas profile | `wiki/robots/` |
| [part.md](part.md) | A part profile | `wiki/parts/<folder>/` |
| [tool.md](tool.md) | A tool, library, framework, policy, model or dataset | `wiki/tools/`, `wiki/software/`, `wiki/learning/` |
| [concept.md](concept.md) | How something works | `wiki/concepts/` |
| [guide.md](guide.md) | A decision guide | `wiki/guides/` |
| [source.md](source.md) | The triage note for one research source | `sources/` |
| [skill/SKILL.md](skill/SKILL.md) | An agent skill | `skills/<prefix>-<name>/` |
| [project/](project/) | A new project's starting files | `projects/<name>/` |
